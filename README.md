## 📖 Tentang Repositori Ini

Repositori ini adalah **rumah digital** untuk buku *"Peta Jalan Seleksi Pendidikan Tinggi"* dan *"Buku Saku Seleksi Pendidikan Tinggi"*---panduan komprehensif dan modular yang memetakan seluruh jalur seleksi masuk pendidikan tinggi di Indonesia: dari SNBP, UTBK-SNBT, dan Seleksi Mandiri PTN, hingga sekolah kedinasan, akademi militer, dan pendidikan vokasi.

Repositori ini memuat:

- 📘 **Materi buku dan soal-soal simulasi dan tryout** dalam format pdf.
- 📝 **Soal latihan tambahan** beserta pembahasannya.
- 📅 **Pembaruan jadwal dan kebijakan** seleksi.
- 🔧 **Template belajar** (jadwal, *error log*, evaluasi tryout).
- 💬 **Ruang diskusi** untuk tanya jawab dan berbagi pengalaman.

Semua konten dapat diunduh, digunakan, dan disebarkan secara bebas dengan tetap mencantumkan atribusi (lihat bagian [Lisensi](#-lisensi)).

## 🎯 Untuk Siapa Buku Ini?

| Pembaca | Manfaat |
|---|---|
| **Siswa kelas 12** (TA 2026/2027) | Peta jalur seleksi, rangkuman materi, dan 300+ soal latihan. |
| **Orang tua** | Panduan memahami jalur seleksi dan cara mendampingi anak. |
| **Guru dan pembimbing** | Materi ajar modular siap pakai untuk kelas persiapan. |
| **Alumni** | Referensi untuk berkontribusi atau membimbing adik kelas. |
